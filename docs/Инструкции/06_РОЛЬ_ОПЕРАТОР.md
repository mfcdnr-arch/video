# 06. Руководство оператора (повседневная работа)

Это инструкция «на каждый день» для человека, который наполняет сеть контентом.
**Отдельной роли `operator` в системе нет** — оператор работает под учётной
записью с ролью `admin`. Здесь собран только ежедневный рабочий цикл, без
администрирования сервера и пользователей.

Цикл одного ролика:
**загрузить → объявить категорию (38-ФЗ) → отправить на модерацию →
собрать плейлист → поставить в расписание → проверить, что играет.**

---

## Требования к контенту (форматы) ⚠️
Чтобы ролик гарантированно играл на мини-ПК:
- **Видео:** контейнер **MP4**, кодек **H.264 (AVC)**, разрешение **до 1920×1080
  (Full HD)**. Это самый надёжный вариант для плеера mpv на Astra Linux.
- **Изображения (баннеры):** JPG, PNG, BMP, WEBP, GIF, TIFF — показываются по
  **10 секунд** (длительность можно изменить при загрузке).
- **Не рекомендуется:** HEVC/H.265, 4K и другие «тяжёлые» кодеки — слабый мини-ПК
  может тормозить или не воспроизвести их. Сервер такой файл **примет с
  предупреждением** — обязательно проверьте его на реальном экране.
- **Будут отклонены:** повреждённые файлы и файлы без видеодорожки/изображения
  (сервере проверяет каждый файл через ffprobe при загрузке).

### Общая медиатека и папки

![Медиатека](img/04_media.png)

Ролик не обязан принадлежать рекламодателю: карточка **«Общая медиатека»**
наверху раздела хранит ролики без привязки. Внутри можно создавать **свои
папки** («+ Папка»), загружать файлы сразу в папку (в форме загрузки
рекламодателя можно не выбирать, а папку — выбрать) и перекладывать ролики
между папками селектом на карточке файла. При наполнении плейлиста ролик
выбирается **по папкам**: сначала папка (Общая / своя папка / рекламодатель),
затем ролик из неё.

![Общая медиатека](img/06_media_common.png)

## Шаг 1. Загрузить ролик — «Медиатека»
1. **Медиатека → Загрузка**: выберите файл (см. «Требования к контенту» выше) и
   задайте **название**.
2. По желанию: **рекламодатель** и **папка**, срок показа **«с/по»**, для
   картинок — **длительность показа** (по умолчанию 10 сек).
3. Нажмите загрузить — файл проверяется сервером (валидность, кодек, разрешение).
   При «тяжёлом» кодеке/разрешении появится предупреждение — не игнорируйте его.

![Форма загрузки](img/07_media_upload.png)

## Шаг 2. Объявить категорию (38-ФЗ) — при загрузке
Это обязательный шаг. Выберите **категорию** ролика — подсказка под полем
сообщит, что делать:
- **«Служебный контент — не реклама»** → модерация не нужна, ролик готов к эфиру.
- **Реклама** → появятся нужные поля: **возрастная маркировка** (например, 18+),
  **дисклеймер** (предупреждение), **номер лицензии** — заполните то, что
  требует категория. После загрузки ролик уйдёт **на модерацию**.
- **Запрещено законом** (например, табак) → загрузка будет **отклонена**, ролик
  не примут. Выберите корректную категорию или не грузите.

> Для рекламы алкоголя нужен экран типа «Магазин с алколицензией» — это
> настраивает администратор в «Экранах». На других площадках алкоголь в эфир
> не выйдет (38-ФЗ, ст. 21).

## Шаг 3. Дождаться модерации
Рекламный ролик получает статус **`pending`** и **не играет**, пока
[модератор](05_РОЛЬ_МОДЕРАТОР.md) его не **одобрит** (`approved`). Отклонённый
(`rejected`) в эфир не пойдёт — исправьте замечание и загрузите заново.
Проверить статус можно в «Медиатеке»/«Модерации».

## Шаг 4. Собрать плейлист — «Плейлисты»
1. **Плейлисты → создать** плейлист, задайте название.
2. Добавьте **одобренные** ролики в нужном порядке; при необходимости настройте
   ротацию.
3. Сохраните.

### Длительность плейлиста и заглушки

![Редактор плейлиста: эфирный блок](img/09_playlist_block.png)

По умолчанию каждый плейлист — **эфирный блок фиксированной длины 60 минут**
(максимум; блок никогда не превышает цель). Если основные ролики короче цели,
свободное время **автоматически и равномерно** заполняется заглушками из
**Медиатека → Заглушки** (служебные ролики: не реклама, без модерации,
загружаются кнопкой «Загрузить заглушки»).

![Папка «Заглушки»](img/05_media_fillers.png)

Панель над списком роликов показывает расчёт: сколько идут основные ролики,
сколько заглушек добавится и итог блока — и **предупреждает**, если:
- основные ролики сами длиннее цели;
- заглушек в медиатеке нет (блок будет короче цели);
- суммарного времени заглушек не хватает (они будут повторяться по кругу).

Галочку «Эфирный блок фиксированной длины» можно снять — тогда плейлист
**произвольный**: играет по кругу как есть, заглушки не добавляются. Целевую
длительность (по умолчанию 60 мин) можно изменить там же.

Показы заглушек видны в **Отчёты → «Заглушки»**: сколько показов и времени в
эфире (всего и по каждому ролику) и состав папки.

## Шаг 5. Поставить в расписание — «Расписание»

![Расписание](img/10_schedule.png)

Выберите уровень показа:
- **Экран** — на один конкретный экран;
- **Группа** — на все экраны группы;
- **Сеть** — на всю сеть (общий эфир).
Задайте время/дни в недельной сетке и, при необходимости, переопределения на
конкретные даты (календарь месяца). Более узкий уровень переопределяет более
широкий (экран > группа > сеть). Полезное: **⧉ Скопировать расписание экрана**
на другой экран; массовое удаление слотов (весь шаблон / день / выбранные).

## Шаг 6. Проверить, что играет
1. **Расписание → 🔎 Симулятор** — что реально будет играть на экране в
   выбранный час (учитывает все уровни, даты, модерацию и тип площадки), ещё
   до реального показа.
2. **Дашборд** — убедитесь, что нужные экраны **онлайн** и играют ожидаемый
   контент.

![Дашборд](img/02_dashboard.png)
3. При проблеме с конкретным экраном — проверьте его статус в «Экранах»
   (офлайн-экран расписание не отыграет).

## Бегущая строка (по необходимости)

![Бегущая строка](img/12_ticker.png)

Раздел **«Бегущая строка»**: текст, цвет, скорость и время показа (0 или
пусто — бессрочно). «Запустить» — строка появится поверх видео на всех
экранах; «Снять» — убрать. При **«Стопе»** показа или **смене плейлиста**
строка снимается автоматически — для нового показа запустите её заново.

- [ ] Обновил/собрал нужные **плейлисты** из одобренных роликов.

## Частые вопросы
**Ролик не появляется в эфире.** Проверьте: одобрен ли он (не `pending`/`rejected`),
входит ли в плейлист, назначен ли плейлист в расписание, не истёк ли срок «с/по»,
онлайн ли экран.

**Не могу выбрать категорию / загрузка отклонена.** Категория запрещена законом
или не соответствует площадке (например, алкоголь на неалкогольном экране) —
уточните у администратора.

**Нет кнопок создания/загрузки.** Ваша учётка не имеет права записи (роль
`auditor`/`moderator`). Для повседневной работы нужна роль `admin` — обратитесь
к [администратору](03_РОЛЬ_АДМИНИСТРАТОР.md).
