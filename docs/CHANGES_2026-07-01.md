## 📋 Основные исправления

### 1. ✅ Замена VLC на mpv

**Проблема:** Была необходимость использовать современный проигрыватель через IPC.

**Файлы изменены:**
- `client/install.sh` (строка 107)
  - **ДО:** `apt-get install -y -q python3 python3-pip python3-venv vlc chrony`
  - **ПОСЛЕ:** `apt-get install -y -q python3 python3-pip python3-venv mpv chrony`
  
- `client/ds_player.py` (полный переход на mpv)
  - Класс `VLCPlayer` (оставлено для совместимости API)
  - Используется JSON RPC через Unix-сокет `/tmp/ds-mpv.sock`
  - Методы: `start_vlc()`, `play()`, `stop()`, `get_status()`
  - Команды отправляются через JSON: `{"command": ["loadfile", "file.mp4"]}`

**Проверка:**
```bash
# На мини ПК проверьте что mpv установлен
which mpv
mpv --version

# Проверьте что есть сокет
ls -la /tmp/ds-mpv.sock

# Проверьте что mpv запущен
ps aux | grep mpv
```

### 2. ✅ Исправление systemd сервиса

**Проблема:** Сервис использовал `graphical-session.target` которого нет в Astra Linux.

**Файл:** `client/ds-agent.service`

**Изменения:**
- **Удалено:** `BindsTo=graphical-session.target`
- **Изменено:** `After=network-online.target chrony.service graphical.target`
- **Изменено:** `Wants=network-online.target graphical.target`
- **Изменено:** `WantedBy=graphical.target`

**Результат:** Сервис запускается после загрузки графической сессии X11.

## 🔍 Критические изменения для внимания

### 1. Путь к mpv сокету

Используется: `/tmp/ds-mpv.sock`

Если мини ПК перезагружается часто, сокет может остаться в `/tmp` и вызвать конфликт. В этом случае:

```bash
# На старте агента
rm -f /tmp/ds-mpv.sock
# Сокет пересоздаётся в ds_player.py
```

### 2. Зависимости между миграциями

Миграции применяются **в порядке номеров**:
- 001 = базовая схема (создание таблиц)
- 002-011 = добавление полей и таблиц
- 012-016 = оптимизация индексов и новые функции

**Нельзя применять миграции в другом порядке!**

### 3. DISPLAY переменная для X11

На Astra Linux мини ПК используется `DISPLAY=:0` для вывода видео через X-сервер.

Если на вашей системе используется другой дисплей, отредактируйте:
- `client/ds-agent.service` (строка 40)
- `client/config.ini` (если используется)

```bash
# Проверьте какой дисплей используется
echo $DISPLAY
# или
who
```

## ⚠️ Известные проблемы

### 1. Интернет на мини ПК

Если интернета нет, pip не сможет установить зависимости. Решение:
```bash
# Скопируйте requirements.txt
# Установите offline:
pip install -r requirements.txt --break-system-packages -f /offline/wheels/
```

### 2. Права доступа на scp

Если `scp` выдаёт "Permission denied", проверьте:
```bash
# На сервере
ls -la /opt/ds-server/client/
# Должны быть права 644 для файлов
chmod 644 /opt/ds-server/client/*.py
chmod 755 /opt/ds-server/client/install.sh
```

### 3. mpv не запускается

Если mpv не запускается, проверьте:
```bash
# На мини ПК
which mpv
mpv --version
# Если не установлен:
sudo apt-get install -y mpv
```
